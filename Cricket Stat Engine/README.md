# Cricket Stats Engine

## Introduction

**Cricket Stats Engine** is a Python-based project designed to process cricket match data and generate meaningful statistics from raw cricket datasets. It uses JSON match data as input and organizes processed statistics into CSV files for further analysis.

The project was developed as a practical Python project to strengthen programming skills, work with structured data, and build cricket-related statistical features.

## Project Overview

The engine works with two main types of data:

- **Raw JSON Data:** Contains the original cricket match information used as input.
- **Processed Statistics:** Stores generated cricket statistics in CSV format.

The project is organized into separate features, allowing different types of cricket statistics to be processed independently.

## Main Features

The engine includes three core features focused on cricket statistics. Each feature is maintained separately and can be integrated into a central program.

- **Feature 1 — Match Scorecard:** Processes match data to display match information, batting scorecards, bowling scorecards, innings totals, and match results.
- **Feature 2 — Cricket Statistics:** A separate feature within the engine for processing cricket data.
- **Feature 3 — Cricket Statistics:** Another independent feature that contributes to the engine's overall statistical functionality.

## Technologies Used

- **Python** — Core programming language
- **JSON** — Raw match-data format
- **CSV** — Format for storing processed statistics
- **Git and GitHub** — Version control and project management

## Project Goal

The goal of Cricket Stats Engine is to transform raw cricket match data into organized and useful statistical information through Python programming. It also serves as a foundation for further development, including integrating its features into a unified application.

## Future Development

Potential improvements include a unified interface for all three features, improved data handling, additional cricket analytics, and a web-based interface.
