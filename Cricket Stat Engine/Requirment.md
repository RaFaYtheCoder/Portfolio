## Installation and Execution

### Requirements

Make sure Python is installed on your system.

The project uses the following modules:

- **pandas** — For handling and processing tabular data.
- **os** — For interacting with the operating system.
- **time** — For time-related operations.
- **json** — For reading and processing JSON data.
- **csv** — For working with CSV files.

The `os`, `time`, `json`, and `csv` modules are included with Python and do not require separate installation.

### Install Dependencies

Open your terminal in the project directory and run:

```bash
pip install pandas
```

If you encounter a `ModuleNotFoundError` for an external package, install the required package using:

```bash
pip install package-name
```

**Example:**

```bash
pip install pandas
```

### Run the Main File

From the project directory, execute the main Python file using:

```bash
python main.py
```

Replace `main.py` with the actual filename or execution command used by your project.
